如何提供流动性并赚取收益

本指南带你从零开始，一步步赚取第一笔 DeFi 收益。我们提供两条路径：路径 A（被动/简单）适合新手，路径 B（主动/进阶）适合追求高收益的用户。

第 0 步：准备工作

1

安装 MetaMask 钱包

访问 metamask.io → 下载浏览器扩展 → 创建新钱包 → 用纸写下助记词（绝对不要分享给任何人！）

MetaMask 是什么？
一个浏览器钱包，让你与 DeFi 协议交互。可以理解为你的"DeFi 银行账户"，私钥保存在你自己的设备上。
2

把资金转到正确的链上

在交易所（Coinbase、Binance）购买 ETH 或 USDC → 提现到你的 MetaMask 钱包地址 → 确保选择正确的网络（如 Base、Ethereum、Arbitrum）。

重要提示
先用小金额（$50-100）学习流程。每条链上都需要少量 ETH 作为 Gas 费（交易手续费）。

选择你的路径

根据你的经验和愿意投入的时间来选择

🛡️

路径 A：被动借贷

存入一种代币，赚取利息。无需管理。

✅ 无无常损失
✅ 存了就不用管
✅ APY：2-10%
✅ 最适合新手
⚡

路径 B：集中流动性LP

提供两种代币设定价格范围。收益更高，需要管理。

⚠️ 有无常损失风险
⚠️ 需要监控和调整
✅ APY：20-100%+
✅ 适合有经验的用户

路径 A：被动借贷（Aave）

最简单的 DeFi 赚取收益方式。在 Aave 上存入 USDC，从借款人那里赚取利息。零管理。

A1

打开 Aave

打开 app.aave.com → 点击右上角 "Connect Wallet" → 选择 MetaMask → 在 MetaMask 弹窗中批准连接。

A2

选择网络和资产

从顶部栏选择网络（Ethereum、Arbitrum、Base等）→ 找到 USDC → 查看 "Supply APY" 列 — 这就是你将获得的收益率。

提示
Arbitrum 和 Base 的 Gas 费比以太坊主网低得多。收益率相同，使用成本更低。
A3

存入（Supply）

点击 USDC 旁边的 "Supply" → 输入金额 → 点击 "Approve USDC"（首次需要，授权 Aave 访问你的代币）→ 在 MetaMask 中确认 → 然后点击 "Supply USDC" → 再次在 MetaMask 中确认。

A4

完成！看着余额自动增长

你的仪表盘现在显示你的存款。余额每秒自动增加。无需任何操作。

被动收益工作原理

你存入：     1,000.000000 USDC
1天后：      1,000.013699 USDC  (+$0.014)
1周后：      1,000.095890 USDC  (+$0.096)
1个月后：    1,000.410959 USDC  (+$0.41)
1年后：      1,005.000000 USDC  (+$5.00 按5% APY)

* 利息每个区块（约2秒）累积。随时可以提取——没有锁定期。

A5

如何提取

回到 Aave 仪表盘 → 点击 USDC 旁边的 "Withdraw" → 输入金额（或点"MAX"提取全部）→ 在 MetaMask 中确认 → USDC（包括赚取的利息）返回你的钱包。

路径 B：集中流动性（Uniswap V3）

更高的回报，但需要两种代币和主动管理价格范围。示例：Base 链上的 WETH-USDC。

B1

打开 Uniswap

打开 app.uniswap.org → 连接 MetaMask → 切换到 Base 网络（左上角链选择器）。

B2

创建新头寸

点击 "Pool" 标签 → "+ New Position" → 选择 WETH 和 USDC → 选择手续费等级（稳定币选 0.05%，ETH/USDC 推荐 0.3%）。

B3

设置价格范围（最重要的一步！）

这决定了你的风险和收益。你会看到一个价格图表和两个拖动手柄。

安全范围（±20%）
APY 较低（约20-40%），但在范围内停留更久。每周检查一次。
激进范围（±5%）
APY 更高（约60-120%），但价格容易离开范围。每天检查。
举例
如果 ETH = $2,000，你设置范围 $1,600-$2,400（±20%），你就能从这个范围内的每笔交易中赚取手续费。如果 ETH 跌到 $1,500 或涨到 $2,500，你的头寸就会停止赚钱。
B4

输入金额并确认

输入 WETH 和 USDC 的数量（界面会根据你的范围自动计算比例）→ 点击 "Approve WETH" + "Approve USDC"（首次需要）→ 点击 "Add Liquidity" → 在 MetaMask 中确认。

B5

监控和领取手续费

进入 "Pool" 标签 → 你会看到你的头寸显示 "Uncollected fees"（未领取手续费），里面是你赚到的 WETH + USDC → 点击 "Collect fees" 将手续费发送到你的钱包（不关闭头寸）。

主动LP收益工作原理

你存入：    0.25 WETH ($500) + 500 USDC = $1,000
价格范围：  $1,600 - $2,400 (±20%)

1周后：     未领取手续费: 0.003 WETH + 4.2 USDC (~$10)
1个月后：   未领取手续费: 0.012 WETH + 17.5 USDC (~$42)

⚠️ 但你的本金会变化：
如果ETH涨10%：头寸 = 0.21 WETH + 580 USDC ($1,042 + 手续费)
            对比持有 = 0.25 WETH + 500 USDC ($1,050)
            无常损失 ≈ $8（但手续费 ~$42 可以抵消）

* 手续费数据为示意。实际手续费取决于每日交易量和你在池中的份额。

B6

何时关闭/调仓

在 Uniswap Pool 页面查看你的头寸：

  • 绿色 "In Range" → 头寸活跃，正在赚取手续费。不需要操作。
  • 红色 "Out of Range" → 价格超出了你的范围。你没有在赚钱。选择：等待价格回到范围内，或者撤出流动性并创建新的范围。

关闭头寸："Remove Liquidity" → 选择 100% → 确认 → 你将收到 WETH + USDC（包含所有手续费）回到钱包。
